# رُكن - نموذج موقع تجريبي
مشروع منفذ مستقل لعرض المهارة، وليس عملاً سابقًا لعميل أو نشاطًا حقيقيًا.
## التشغيل
افتح index.html مباشرة. لا تثبيت ولا إطار عمل ولا اتصال إنترنت مطلوب. للرفع، ارفع كل الملفات بنفس ترتيب المجلدات على استضافة ملفات ثابتة.
## تعديل المحتوى
عدّل data.js: id فريد، name، category، price رقم، image اسم الصورة دون الامتداد، subtitle، description، details قائمة نصوص. ضع الصور JPG في assets. تتولد الأقسام تلقائيًا. عدل الاسم والعناوين والألوان من index.html وstyles.css.
## التفاعلات
بحث، تصفية حسب القسم، ترتيب السعر، حالة فارغة وإعادة ضبط، تفاصيل حوارية، إغلاق بزر أو Escape، عودة تركيز لوحة المفاتيح، أسئلة قابلة للفتح، روابط تنقل داخل الصفحة، تحويم، استجابة للموبايل.
## الحدود
لا لوحة إدارة أو حفظ على خادم أو دفع أو تواصل أو تتبع أو تسجيل. الصور مولدة والبيانات والأسعار افتراضية للتوضيح. لا يُقدَّم كنشاط حقيقي أو مشروع عميل. استبدلها ببيانات وصور مصرح بها قبل الاستخدام التجاري. لا استضافة أو نطاق مدفوع مشمول.

## الصور في نسخة GitHub
الصور المولدة مضمنة في images.js كسلاسل بيانات لتعمل الملفات دون تنزيل خارجي. لا حاجة لمجلد assets في هذه النسخة. لتغيير صورة عدل القيمة المطابقة لاسمها في window.DEMO_IMAGES.
